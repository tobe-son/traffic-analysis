# 専攻科研究 I 中間報告書（素案）

## 交通通過音による速度推定のドメインギャップ低減

### 1. 背景と目的

交通速度の把握は道路安全や都市計画に重要である。マイクによる計測は低コストで、映像を保存しない構成にできる一方、車種、背景雑音、マイク、設置地点の影響を受けやすい。昨年度は深層距離学習による交通音表現と速度回帰を検討した。シミュレーションでは最高 R2=0.955 だったが、実環境では全条件で R2<0 となった。最良でも ArcFace-small の R2=-0.019、MAE=16.932 km/hであり、モデルの大規模化より simulation-to-real の差が主要課題である。

本研究の目的は、未知地点・未知車両に対して妥当な評価系を構築し、周波数方向正規化とゲイン・背景雑音拡張によって実環境性能を改善することである。実環境 R2>=0、既存最良値から MAE 10%以上低減を成功基準とする。

### 2. 方法

既存の Circle Loss、ArcFace、Log-ratio Loss によるエンコーダを基準とする。シミュレーションデータは6地点の leave-one-location-out、VS13は13車両の leave-one-vehicle-out で分割する。比較条件は、A:既存前処理、B:周波数方向正規化、C:ゲイン・雑音拡張、D:B+Cの4条件である。各条件をseed 42-46で反復し、主指標に実環境 R2、副指標にMAE、RMSE、simulation-to-real R2 gapを用いる。サンプル単位予測に対し2,000回の対応付きbootstrapで95%信頼区間を算出する。

### 3. 現在までの結果

昨年度の速度回帰結果を同一基準で再集計した。simulation の最高値は LogRatio-resnet18 (R2=0.955) だが、real では R2=-1.436だった。一方、real の最良は ArcFace-small (R2=-0.019, MAE=16.932 km/h) で、同モデルの simulation R2 は0.493である。この順位逆転は、simulation 内の性能だけでモデルを選ぶ手順が実環境性能を保証しないことを示す。集計処理を独立したCLIとして実装し、テストデータで指標計算、モデル選択、bootstrapの再現性を確認した。

### 4. 考察、困難への対応、今後

実環境で負の R2 となることから、現在のモデルは平均速度を予測する単純な基準を安定して上回れていない。原因候補は、シミュレーションに含まれない背景雑音と伝達特性、車両固有音への過適合、分割時の独立性不足である。そこで今年度は評価単位を地点・車両へ変更し、まず評価の楽観性を除く。その後、正規化と拡張を別々に検証して原因を切り分ける。今後は条件Aのgroup-wise再現、B-Dのablation、5 seed集計を順に実施し、仮説が不支持の場合も信頼区間と失敗分析を報告する。
