# 今年度の実施成果と来年度への接続

この文書は先に作成したplan.md・interim_report.mdの位置づけを更新する。
今年度はデータ・チャンネル・入力分解能の評価基盤と予備検証を扱い、来年度にAttention付きモデルの本格比較へ進む。以前設定したR²やMAE改善率は提案値であり、達成済み結果でも指導教員合意済みの条件でもない。

## 今回実施したこと

1. 既存コードの静的監査。real_data_tool/audio_utils.pyのload_and_normalizeはmono=Falseでもdata[:,0]を選び、ステレオを保持しない。resample_linearは補間のみで、明示的なアンチエイリアスフィルタがない。
2. learn_tool/settings.pyでは全特徴の最小最大を算出してからtrain_test_splitしている。検証データが正規化統計へ入る。性能低下の原因と断定はできないが、未知環境評価の前に修正すべき点である。
3. 独立モジュールaudio_protocol.pyに、左右保持、L/R平均・片側選択、polyphaseリサンプリング、グループ分割、学習集合のみのスケーリング統計計算を実装した。既存学習ローダーへの統合は未実施。
4. 48 kHzの合成正弦波を8 kHzへ変換する機構検証を実施した。交通音モデルの学習や精度実験ではない。

|入力周波数|単純間引きRMS|フィルタ付きRMS|右/左RMS比|
|---|---:|---:|---:|
|1 kHz|0.707107|0.707692|0.25|
|7 kHz|0.707107|0.000176|0.25|

7 kHz成分は8 kHz標本化のナイキスト周波数を超える。単純間引きでは折り返し成分が残るが、フィルタ付きでは約72 dB抑制された。左右振幅比は保持された。したがって低解像度仮説を検証する際に、間引きによる人工的特徴の混入を防げる。ただし低解像度で認識精度が改善するという仮説自体は未検証である。

## 今年度の実験計画

- データ台帳：原音パス、録音事象ID、車両ID、地点、マイク、物理チャンネル、標本化周波数、速度と単位、方向の定義、ライセンスを記録する。未確認ラベルを推測で埋めない。
- IDMTの同一通過事象を別マイクで収録した音や派生クリップは同じ分割に配置する。単にファイル名が違うことを独立性とみなさない。
- モノラル／ステレオ：同じ原音と分割でL、R、(L+R)/2、[L,R]を比較。共通ゲインを用い左右別のピーク正規化はしない。左右反転時の方向ラベル定義も確認する。
- 分解能：先生の「解像度」が時間標本化、振幅量子化、波形の包絡・平滑化、時間周波数画像のどれを指すかは未確認。まず標本化周波数を独立した軸として8/16/32 kHzで比較する。原音より高い周波数へアップサンプルして情報量が増えたとは扱わない。
- STFTは窓長・移動幅を秒で固定し、標本化周波数と窓時間の効果を混同しない。波形そのものの粗視化とは別実験として報告する。
- 実環境への無適応転移と実データでの再学習を別条件にする。未知車両評価は原車両IDを保持して実施し、ハイパーパラメータはテスト集合で選ばない。
- 主指標はタスク別に設定：車種・方向はmacro-F1と混同行列、速度はMAE/RMSE/R²。新しい分割でbaselineを再測定してから比較する。旧分割の16.932 km/hを直接の合否基準にしない。
- 反復と不確かさ：seed反復を報告し、同一録音由来サンプルを独立とみなさないグループ単位bootstrapを設計する。既存domain_gap.pyのサンプルbootstrapは独立サンプルのみに適用する。
